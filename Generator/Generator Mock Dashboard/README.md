# Generator Icons App

This project is a simple web application that displays various generator icons along with their information. The application is structured to allow easy updates and modifications using standard web technologies.

## Project Structure

```
generator-icons-app
├── index.html        # Main HTML document
├── css
│   └── styles.css    # Styles for the application
├── js
│   ├── main.js       # Main JavaScript file for dynamic behavior
│   └── icons-data.js # Data file containing generator icon information
├── assets
│   └── icons         # Directory containing icon images
├── package.json      # NPM configuration file
└── README.md         # Project documentation
```

## Getting Started

To get started with this project, follow these steps:

1. **Clone the repository**:
   ```
   git clone <repository-url>
   cd generator-icons-app
   ```

2. **Install dependencies** (if any):
   ```
   npm install
   ```

3. **Open the project**:
   Open `index.html` in your web browser to view the application.

## Usage

- The application will display a grid of generator icons.
- Each icon will show its name, description, and image.
- You can update the icon data by modifying the `js/icons-data.js` file.
